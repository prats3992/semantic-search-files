# Natural Language Processing (NLP) Basics

NLP is a field of AI that deals with the interaction between computers and human language.
It enables computers to understand, interpret, and generate human language in a valuable way.

Core NLP tasks include:
- **Tokenization**: Breaking text into words or sub-words.
- **Part-of-Speech Tagging**: Assigning grammatical categories to words.
- **Named Entity Recognition**: Identifying entities like names, locations, organizations.
- **Sentiment Analysis**: Determining the emotional tone of a text.
